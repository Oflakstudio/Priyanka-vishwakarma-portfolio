# Priyanka Vishwakarma — Fashion Portfolio

A from-scratch editorial fashion design portfolio built with React + Vite and deployed with GitHub Pages.

## Local development

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

## Content

Project content lives in `src/data/projects.js`. Replace the clearly marked placeholders with Priyanka's real project information and add final photography, sketches, research boards, and other portfolio imagery as local assets.

## Deployment

GitHub Actions builds `dist` and deploys it to GitHub Pages on pushes to `main`.

Repository: https://github.com/Oflakstudio/Priyanka-vishwakarma-portfolio
